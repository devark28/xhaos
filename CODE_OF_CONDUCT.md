# Code of conduct

Xhaos follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, patient and respectful; criticize ideas, not people; assume good intent; and accept that maintainers decide what fits the project. Harassment, insults, and personal or political attacks are not tolerated, in issues, pull requests, discussions, or anywhere else you represent the project.

## Reporting

If someone's behaviour concerns you, report it privately to the maintainer through GitHub (the repository's **Security** tab → **Report a vulnerability** is private and reaches the maintainer; mark it as a conduct report). Reports are kept confidential. The maintainer may remove comments, commits or contributions, and may block anyone who breaks this code, as described in the Covenant's enforcement guidelines.
